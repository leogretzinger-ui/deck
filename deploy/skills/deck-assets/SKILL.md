# Files for the person

Files meant for the person you work with, such as screenshots, exports and
reports, go in `.deck/assets/` at the project root. Deck shows them in the
Assets panel.

The same path is in `NOISEDECK_ASSETS_DIR`, relative to the project root.
Create the folder if it does not exist yet.
