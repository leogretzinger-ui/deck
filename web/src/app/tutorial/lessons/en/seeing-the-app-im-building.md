# Seeing the app I'm building

## Turn previews on for a project
advance_on: continue
primary: Preview…
action: preview-settings

Choose Preview… from the project menu and tell Deck how to start your dev server.

## Start the server and open it
advance_on: continue
primary: Open preview
action: open-preview
command: noise deck preview run

Run the launcher in a terminal in the project, then choose Open preview.

## What previews are not
advance_on: continue

A page that loads isn't proof the app works, so still run your tests. The dev server shares the workspace with your agents, so don't preview code you don't trust.
