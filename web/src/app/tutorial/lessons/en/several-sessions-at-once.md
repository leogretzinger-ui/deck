# Several sessions at once

## Start another
advance_on: continue
primary: New session
action: new-session

Choose + on the project row to start a second session. It can be a different agent.

## Switch between them
advance_on: continue

Select a session in the side panel to bring it forward. The others keep running. Rename a session from its row menu to tell them apart.

## Close one
advance_on: continue

Closing a session ends its process, so Deck asks you to confirm first. You can turn that off in the global menu.
