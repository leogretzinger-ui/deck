# Tasks from a brief

## Add a PRD
advance_on: continue
opens: tasks
primary: Add PRD…
action: add-prd

A brief is a Markdown file that says what you want. Add it to a project from the Tasks panel.

## Generate tasks
advance_on: continue
primary: Generate tasks
action: generate-tasks
generate_count: 2
primary_note: Uses your Claude plan or API key.

Choose Generate tasks to fill the board from the brief. Try it on the relnotes PRD from lesson 1, then read the tasks it makes. You can edit or delete any of them.

## Work the board
advance_on: continue

Add tasks by hand, search, or filter by status or priority. Open a task to see its details.
