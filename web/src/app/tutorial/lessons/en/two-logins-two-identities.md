# Two logins, two identities

## Deck's login and the agent's login
advance_on: continue

You sign in to Deck in the browser. Each agent signs in separately, in its own terminal, so Sign out in Deck doesn't sign an agent out.

## Git identity and GitHub
advance_on: continue
primary: Git identity…
action: git-identity

Set the name and email on your commits with Git identity, in the global menu or per project. Choose Connect GitHub separately so Deck can clone and push to your repositories.

## The switches
advance_on: continue

Yolo mode lets new sessions skip permission prompts. Two confirmation settings ask before you close a session or remove a project. All three are in the global menu.
