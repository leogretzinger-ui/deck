# What an agent here can reach

## What an agent here can reach

Deck runs coding agents natively on this machine: an agent can read and change anything under `/workspace`, including other projects, and it can use any credential the runtime holds, such as your GitHub login. A project folder is not a wall between agents (yet).

Deck itself listens on this computer only, keeps no transcripts, and never sends anything on your behalf. And whatever coding agents natively do, whether they send data or don't, we don't change that behavior.

Give an agent only what you would give every agent.
