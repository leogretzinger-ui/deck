# Files and uploads

## Browse
advance_on: continue
opens: files

Files shows the selected project's working tree. Open folders, read text and view images. To change a file, edit it in your editor or ask the agent.

## Upload
advance_on: continue
primary: Upload files
action: upload-files

Drop files into the open folder, or choose Upload files. Each file can be up to 32 MiB. If a name already exists, choose Replace, Upload as, or Cancel.

## When an upload is unsure
advance_on: continue

If an upload reports an unknown result, look in the folder before uploading again.
