# What my agents remember

## One memory for all agents
advance_on: continue

MemPalace is a shared memory that every agent on this Deck can search and write to. What one agent saves, the next one can find.

## How agents use it
advance_on: continue

Agents search it before answering questions about past work, and save notes at milestones. Nothing is added from your projects automatically.

## Looking at it yourself
advance_on: continue
command: mempalace search "release notes"

To see what's in it, run `mempalace search` in any terminal.
